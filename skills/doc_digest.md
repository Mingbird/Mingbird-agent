# 长文速读
1. 定位文件:list_dir + read_file 开头确认是什么、多长;超大文件用 run_python 数行数、按行切片。
2. 分块读:每块 300~500 行(read_file 或 run_python 切片),逐块提取:讲了什么、关键数字、人名/日期/结论。
3. 边读边记:每块一句话要点(记在对话里,不写中间文件)。
4. 产出 create_file 写摘要文件(markdown):
   - 一段话总述(≤150 字)
   - 要点清单(每条一行,带原文位置如 L120)
   - 关键数字/日期/人名表
   - 行动项(如果文中有待办/结论指向的行动)
   - 原文未回答的问题
5. 用户只要口头摘要就不要建文件,直接 finish。
注意:绝不跳读关键段(数字、结论、表格);摘要里区分"原文说的"和"我推断的"。
