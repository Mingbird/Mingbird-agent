# Web UI 使用指南

鸣鸟为**同一个 agent 内核**提供两种前端：桌面客户端（`agent_gui.py`，安装包内置）与
**本地 Web UI**（`webui/server.py`，跑在浏览器里）。两者驱动同一引擎
（`ollama_agent.py`），因此会话、技能、MCP 服务器与设置完全共享。

## 启动 Web UI

前置：Python 3.12、[Ollama](https://ollama.com)（已拉取至少一个模型）。在仓库根目录：

```
pip install -r requirements.txt      # 一次即可
python webui/server.py               # 服务地址 http://127.0.0.1:8765
python webui/server.py --port 9000   # 自定义端口
```

用浏览器打开打印出的地址即可。服务**只绑定 127.0.0.1**——网络不可访问、无账号、无遥测。
请不要做端口转发或内网穿透：Web UI 没有鉴权，设计上只在本机使用。

## 浏览器里能做什么

- **对话页**——选模型，输入任务，`Ctrl+Enter`（或 `Cmd+Enter`）发送。输出逐字流式；
  思考过程在可折叠块里可见，答案开始时自动折叠。`停止`终止运行，`续跑`接着跑被打断的
  任务，`新对话`开启全新会话。
- **历史页**——列出历史会话；"载入并续跑"把该会话接进浏览器（下一条消息追加其上），
  "查看对话记录"显示原始消息。
- **设置页**——上下文窗口、温度、输出上限、思考开关、自定义系统提示。保存在
  `~/.ollama_agent/gui_prefs.json`，**与桌面版共用**：一边改，另一边下个任务生效。
- **计划 (todo) 面板**——agent 的实时待办清单，与桌面版侧栏一致。
- **主题与语言**——自动/浅色/深色主题、英文/中文切换，均本地记忆。
- **任务时限**——任务描述里写"40 分钟"/"限时 40 分钟"，临近时限自动收尾，与桌面版一致。

## 桌面版有、Web UI 还没有的

- 语音输入（内置 STT 模型目前只接在桌面客户端）。
- 文件/截图的拖入与粘贴附件。
- 附件面板；Web 端附件上传在路线图上。

其余一切——工具执行、安全门、会话记忆、MCP、技能——都是同一个引擎，行为与桌面版一致。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| "Ollama ✗" 红点、模型下拉置灰 | Ollama 没启动（`ollama serve`）或没拉模型（`ollama pull qwen3.5:4b`）。启动后自动恢复。 |
| 端口被占用 | `python webui/server.py --port 9000` |
| 断线重连后聊天内容重复 | 旧版本会回放事件积压；当前版本只推新事件——请更新。 |
| 浏览器里改的设置桌面版没生效 | 两边读同一文件，**下个任务开始时生效**；正在跑的任务沿用其设置。 |

## 数据都在哪

| 数据 | 位置 |
|---|---|
| 会话 | `~/.ollama_agent/sessions/*.json` |
| 设置（两个前端共用） | `~/.ollama_agent/gui_prefs.json` |
| 任务工作目录 | `~/agent_tasks/work`（运行中切换目前仅桌面版支持；Web UI 固定用默认目录） |
