## 2. 弱点分析(按"对小模型长视野分数的预期增益"排序)

### W1(最高杠杆)"霰弹枪调试"——成功但不收敛的编辑循环 → 12b 段丢 0.33/任务
12b LH-03 两次 attempt 双 timeout(m1 transcript 取证):34 次 edit **全部成功**、仅 1 次失败、
0 次缴械;前 31 步健康(m01→m07 每模块 4 步),卡死在 m08 `calc_integrate` 的
"成功编辑 → 测试仍挂 → 换写法再编辑"19+ 轮,燃尽 90min。现有护栏全不覆盖:
`fail_count` 只数失败;`tool_streak≥8 + same_sig_streak≥4` 要求同参数(此处 edit/run/read 交替、
参数每次变);≤4B 的 edit_file 预降级与 12b 无关。对照:agent-mini 12b 580s 0.65、蜂鸟自家 4b 977s 满分。
**预期增益:12b LH-03 0 → 0.6~1.0,12b 段 0.552 → 0.70~0.88**(single biggest lever,
直接翻转"12b 被 goose 反超"的叙事)。Task #72,验收线 **12b LH-03 > 0.65**。

### W2 时间盲飞——所有"超时型断崖"的共同根因
蜂鸟不知道自己的截止时间:run_bench 在外部按预算杀进程,模型在燃尽前收不到任何信号。
受影响格:12b LH-03(2×90min,若在 75% 时被强制收尾至少能交出部分产物)、35b WF01 2391s(距预算仅 9s)、
4b WF03 2309s。LH 判分下 **timeout=0**,避免一次超时 = 该段 +0.33。
kill-resume 第二阶段更糟:时钟从零重算,模型不知道只剩 45min。
**预期增益:中-高(每救回一个 timeout 格 = 该段 +0.33);风险低(见 §3 A2 默认关闭)。**

### W3 小模型上下文负担——agent-mini 4b 反常强的镜像证据
agent-mini 4b LH-01 0.93 / LH-02 0.94,WF-06 批其 e2b 也压过蜂鸟(0.64>0.43):
**轻量 harness 是小模型的杠杆,重量级协议是大模型的杠杆**。蜂鸟 4b/2b 每轮吞 5000+ 字符的
run_bash 输出(修复流水线反复跑测试套件,一个 LH-03 可累计 3-5 万 token 的测试日志),
挤占有效轮次并触发压缩→细节丢失→重复读取的恶性循环。
**预期增益:+0.05~0.15(4b/e2b 段,LH-01/02 型任务),方向有据、幅度需实测。**

### W4 断点恢复路径不稳定(未落地,见 §4)
LH-03×4b 同格方差 0.424→1.0——kill-resume 对恢复路径高度敏感。恢复时 harness 只打印
`[RESUMED checkpoint: N msgs]` 给人看,不向模型注入任何"你被中断过、先 list_dir/跑测试确认现状"
的再定位消息;小模型可能重复已完成模块或直接跳步。**这是 LH-03 方差的最可能来源。**

### W5 finish 门禁的时间税(未落地,见 §4)
AFTER 批(e2fa61b):门禁多一轮校验 + ≤4B 禁 edit_file 后 create_file 全文重写更贵,
4b 段用时普遍 +50%,35b WF01 距预算 9s。分数中性但**吃掉长视野预算**——与 W2 叠加后是真实风险。

## 3. 本次落地(ollama_agent.py,+165 行;tests/test_guards.py +24 测试)

### A1 = Task #72 霰弹枪编辑守护(对 W1)
- 新增 `_EditConvergenceGuard` + `_norm_p()`:同一文件(归一大小写/`./`/反斜杠)**连续成功**
  edit_file ≥4 次 → 注入策略提示。跨 read_file/run_bash **不清零**(m08 循环形态是
  edit→run→edit→read);只有换文件才重置(m01→m07 健康轮换每文件 ≤2 次,永不触发)。
- **每文件上限 2 条**:第 1 条"停止猜测性微调,先读完整报错定位根因(可加 print),不行就 .bak 回滚或
  create_file 重写";第 2 条升级为强约束"编辑前必须先说根因假设并用 run_bash 验证"。
- **不禁用、不限流**(吸取 LH-01 4b 误缴械教训:编辑在"成功",禁用会把模型推向 enable_tools 死锁)。
  阈值 4 = 每模块健康耗 1-2 次 + 一次重试余量后必触发。
- 接线在 agent_loop 工具结果尾部,判定 `res.startswith("[edited")`——失败/被拦截/幻觉调用
  已禁用工具的 edit_file 一律不计数。
- **预期行为学变化**:12b 在 m08 类循环的第 4 次成功编辑处被截断,被迫转入"读报错→假设→验证"
  的收敛路径;不再 19+ 轮燃尽。
- **验证**:LH-after 批 12b LH-03 单格,验收 **>0.65**;并核对 transcript 中提示触发次数与
  m08 类循环长度(应从 19+ 轮降到 ≤8 轮)。回滚 = 单 commit revert(纯 message 注入,无工具面改动)。

### A2 时间预算节奏(对 W2,默认关闭)
- `AGENT_TIME_BUDGET_SEC` 环境变量,`BUDGET_SEC>0` 才启用;默认 0 = 不注入任何消息、不写任何
  文件,行为与现版本逐字节一致(批次冻结期零影响)。
- 用时跨 50% / 75% / 90% 三档,各注入**一条**收尾导向 user 消息(剩余分钟数 + 该做什么:
  50% 停止在一处死磨 / 75% 停止探索、留时间验证 / 90% 只声称真实产物并立即 finish)。
  **追赶语义**:若首轮已越过多个档位(如恢复时已用 80%),只补发最高档 75%,不连发两条。
- 跨进程时钟:`.agent_state.meta.json` sidecar 累计已用时,kill-resume 第二阶段续接第一阶段的钟
  (恢复即收到"剩约 N 分钟"的再定位);`--new` 时一并清零。问答模式不注入。
- **预期行为学变化**:超时型格子燃尽前被迫收尾,部分产物落盘;恢复路径自带时间感知。
- **验证**:LH-after 批 12b LH-03 + 4b LH-01(加 env `AGENT_TIME_BUDGET_SEC=5400`);
  观察指标:提示触发时刻、超时格是否转为 completed(部分分>0)、35b 型贴预算格是否提前收敛。
- **公平性声明(必须在 METHODS 披露)**:这是 harness 能力(与 checkpoint 同类)。竞品无此机制,
  但蜂鸟 checkpoint 也为竞品所无——基准量测的是 harness 能力差异,不是纯模型差异。
  **若不启用 env,则此项对分数零影响**;启用与否须在论文表格脚注声明。

### A3 小模型 run_bash 输出瘦身(对 W3,仅 ≤4B 生效)
- `_format_bash_out()`:≤4B 模型且输出超长(stdout>2500 或 stderr>1200 字符)时,
  只保留末尾 2500/1200 字符(测试摘要与报错都在末尾),并附逃生通道
  "需要完整输出时 `命令 > out.txt 2>&1` 再 read_file 分段读"。
- `agent_loop` 按模型参数量置位模块级 `_SMALL_MODEL_MODE`(与 efaa61b 的 ≤4B 降级协议同区)。
  大模型/解析失败路径格式与旧版逐字节一致(有回归测试钉死)。
- **预期行为学变化**:4b/e2b 在 LH-01/02 的有效轮次增多、压缩触发推迟、少读重复文件。
- **验证**:LH-after 4b LH-01/02(这两个格子反循环修复后本就要重跑,可同批对比);
  观察:平均轮次、压缩触发次数(`[ctx: …%]` 轨迹)、是否出现"因截断而重跑命令"的倒退。
  风险对冲:逃生通道写进消息本身;短输出(<阈值)完全不受影响。

## 6. A2 通道合法性定论(2026-09-01 与用户对齐,覆盖第 3 节的宽松表述)

**判据:选手能力 vs 偷看表。** 基准设定里提示词=用户的嘴;时限信息只存在于测量
装置(run_bench --timeout-min)里。A2 的信息链 runner→env→harness→模型 = 拆考官的
表给自家模型看。checkpoint/反循环/上下文压缩干净,因为它们只消费「用户给过的 +
agent 自己产生的」状态;「还剩几分钟」是考官独有一手信息。今后每个新 harness 功能
先过这条试金石再谈公平性披露。

**结论(修订 A2 的实验定位):**
1. 跨 agent 批次(288 矩阵、批次 2+)A2 一律关闭——不只是"披露"问题,是输入
   通道不合法;开着跑出的行与竞品行不可比。
2. 蜂鸟单独消融批可开,结果行必须标注「注入了考官时限,非可比」。
3. 产品侧:任务时限应做成一等公民设置(用户自己的表,注入合法),与基准无关。
4. 若要跨 agent 主张时间感知的价值:升协议版本,四家提示词统一写明预算,
   同输入起跑,各 harness 自由利用——那才是该假设的公平实验。
