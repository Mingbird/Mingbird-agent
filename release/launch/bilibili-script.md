## 分镜脚本

### 0:00–0:30 钩子(黑屏大字 + 实物镜头)
> 你是不是也觉得,AI agent 这种东西,得有一张好显卡、或者充云 API 才能玩?
> 这台电脑,只有 核显,没有独显,内存普通。
> 今天它跑了一个能写代码、跑测试、查资料、整理文件的 AI agent。全程离线,数据不出这台机器。

【切屏:实测长任务片段】「它现在正在自己写一个 Python 程序,然后自己跑测试修 bug——注意看,它出错了,自己改,再跑……」

### 0:30–1:50 为什么小模型 agent 容易翻车(痛点)
> 你可能在别的视频里见过:本地小模型跑 agent,对着一句"你好"就开始演示工具、来回打转、或者做错了还嘴硬。
> 根因:小模型不会自己 debug 自己。出错→猜→再错→循环。
> 所以蜂鸟的路线不是"换更大的模型",而是**让 harness 替模型把不会的事扛起来**。

### 1:50–3:30 三个核心设计(配动画/截图)
1. **harness 亲自跑测试** —— 模型写完代码,harness 跑 pytest,把"哪个文件哪一行什么错"精确喂回去,还自动备份每一次修改(.bak),改坏了能一键回滚。
   【截图:日志里 FAILED 那一行,高亮 file:line】
   【数据点:一次对照实验里,2B 模型从 42 次迭代卡死 → 19 次内自己修好】
2. **工具按类别按需加载(扁平 prefill)** —— 不是把所有工具一次性塞给模型。查资料只加载 8 个工具,写代码加载 12 个。上下文开销省一半以上,响应更快。
3. **问答 / 任务分层** —— 闲聊就轻量回答、答完即停;你派真任务,才解锁全套工具。彻底消灭"你好→20 步工具演示"死循环。

### 3:30–4:40 安装演示(录屏)
> 装 Ollama → 拉模型 → 双击安装包 → 桌面快捷方式。就这么简单。
> 双版本:中文「蜂鸟」/ 英文「Hummingbird」,装哪个全凭心情。
> 自带语音输入,本地转写,约 20 倍实时速度,断网也能用。

### 4:40–5:50 现场派活(3 个任务实测)
1. 「帮我写个快速排序,顺便写测试跑过」——【快进,高亮测试全过】
2. 「帮我查一下 XXX,整理成报告」——【切到网络工具在跑】
3. 「帮我整理这个文件夹里的照片/文档」——【文件工具】

### 5:50–6:40 诚实的边界(建立信任)
> 得说清楚:2B 这种小模型,不会一次性帮你重写整个项目。那是 35B 或者云端大模型的事。
> 但它能稳定干 80% 的日常活。而且它干不了的时候,会**响亮地告诉你做不到**,而不是默默做错——这一点我觉得比什么都重要。

### 6:40–7:10 结尾
> 软件完全开源,Apache 2.0,没有遥测,没有账号,不用联网。
> 下载链接在评论区/简介。要是你手头也是台核显本,试试回来告诉我它帮你干了什么活。
> 别再用"我电脑跑不动"当借口了——蜂鸟就是给 95% 的人做的。
