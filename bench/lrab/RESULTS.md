### 64 格关键结论

1. **蜂鸟总均值第一（0.864，第二名 goose 0.518 领先 0.35）**，且**四个模型段全部第一**——
   16 格中 14 格为四家同段最高分。唯一无小模型断崖的 agent（35b→e2b 保留率 70%；
   opencode 0%、goose 44%、agent-mini 无 35b 可保留）。
2. **agent-mini 35b 四格全 0**（26-144s，failure_mode=early_finish）：模型写完计划后输出
   纯文本即被其 harness 当作最终回答——WF-06 批观察到的模式跨 4 任务复现，是该 harness
   的结构性缺陷而非模型能力下限。
3. **opencode 小模型断崖最深**：e2b 四格全 0（45-77s 内退出）。goose 波动最大
   （12b 两格重跑仍 0.00，但 WF-15 12b 0.93）。
4. 蜂鸟 e2b 0.679 与 12b 满分格（WF-01/WF-03）显示：harness 协议设计（扁平 prefill +
   类别路由 + verify 门禁）能在小模型上托底——4B/2B 段蜂鸟分别领先第二名 0.30/0.26。
5. 重跑方差：蜂鸟 3 个超时格重跑全过（attempt1 2400s 整超时 → 重跑 1220s 满分），
   同格方差主要来自核显解码速度；goose 12b 两格重跑仍 0.00，说明"重跑可救超时、救不了能力"。

1. **蜂鸟均值第一（0.79）**，且是唯一 35b 与 12b 双满分的 agent；12b 满分耗时

3. **e2b 段蜂鸟第二**（agent-mini 0.64 > 蜂鸟 0.43）：agent-mini 轻量 harness 在
   2B 级模型上反而占优——如实报告；蜂鸟优势集中在 ≥4B 区间。
4. **opencode 的 0 分是真实能力失败**，非环境故障：12b/e2b 读任务后无产物
   （no_artifacts），4b 干满 17 min 但无视 exact-filename 要求、产物全部改名
   （completed 但 0 分）。35b→小模型的指令遵循崩塌是 LRAB 要量化的核心现象。
5. **蜂鸟 4b（0.71）> 竞品 4b（0.57）**，验证"扁平 prefill + 类别路由"对中档
   模型的兜底作用。

### 预算教训（方法学披露）

旧批 25 min 预算产生过 5 个 timeout"失败"；40 min 预算下同样的格全部正常完成
（goose-12b 旧批超时×2，本批 1812s 满分；蜂鸟-12b 干净环境 712s 0.929 / 矩阵内
1013s 满分）。**小模型超时≠能力不足，先排除预算与环境污染再定结论。**
2026-08-28 晚的 2h 系统休眠曾毁掉一批运行——run_matrix 现内建 keep-awake
（SetThreadExecutionState，进程级，不改系统设置），长矩阵不再依赖外部进程存活。

### 单任务快照的方差警告

WF-06 单任务格间存在真实方差（蜂鸟-12b 两次运行 0.929/1.0；opencode-4b 历史
1.0 → 本批 0.0）。单任务矩阵是快照，不能当稳定均值引用；论文结论以
4agent×4model×15task=240 格全集（当前 16 格）或多样本子集为准。

### 方法学声明（AFTER 批）

- **门禁分数中性**：判分器只读 workdir 实际产物、不读 finish 声称文本，门禁只改变
  "何时允许停"，不直接改变任何 rubric 判定。
- **n=1 不可归因**：逐格 ±0.1~0.3 的波动在 BEFORE 批内部方差量级内（同格重跑
  0.86→0.86、timeout→1.0 均有先例）；e2b 段 +0.071 与 4b 段 −0.036 方向相反，
  均不构成统计结论。改进的价值主张是**行为学证据**（谎报被拒、轨迹不再死循环
  edit_file），不是本轮分数差。
- **用时代价**：门禁多一轮校验 + create_file 重写比 edit_file 多 token，4b 段用时
  普遍 +50%（1155→1849s 等），仍全部在 40min 预算内；35b WF01 用时 2391s 距
  预算仅 9s——长视野任务上这是真实风险（LRAB-H 将量化）。
- 数据：`eval_results/AFTER_SUMMARY.md`；BEFORE manifest 快照
  `eval_results/MATRIX_MANIFEST_BEFORE64_0829.json`（run_matrix 每批覆盖写
  MATRIX_MANIFEST.json，跨批对比须用快照）。
